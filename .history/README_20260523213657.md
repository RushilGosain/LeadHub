# LeadHub - Service Lead Distribution Platform

A modern, production-ready B2B service lead distribution platform built with Next.js, React, Supabase, and Tailwind CSS.

## 🎯 What It Does

**LeadHub** connects customers with service providers through an intelligent lead distribution system:

1. **Customers** submit service enquiries (plumbing, electrical, carpentry, etc.)
2. **System** automatically distributes leads to the most suitable providers
3. **Providers** instantly see new leads on their dashboard
4. **Real-time updates** without page refreshing
5. **Fair distribution** algorithm ensures even workload across providers

## 🚀 Quick Start (5 Minutes)

### 1. Prerequisites
- Node.js 18+
- pnpm (or npm/yarn)
- Supabase account (free at supabase.com)

### 2. Get Supabase Credentials
1. Go to [supabase.com](https://supabase.com)
2. Create free account
3. Create new project
4. Go to Settings → API → Copy:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 3. Install & Setup
```bash
# Clone/extract project
cd lead-distribution-system

# Install dependencies
pnpm install

# Create .env.local
cat > .env.local << 'EOF'
NEXT_PUBLIC_SUPABASE_URL=your_url_here
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key_here
NEXT_PUBLIC_DEV_SUPABASE_REDIRECT_URL=http://localhost:3000/auth/callback
EOF

# Start development server
pnpm dev
```

### 4. Open Application
```
http://localhost:3000
```

### 5. Create Test Account
- Go to `/auth/sign-up`
- Create account
- Verify email (check inbox/spam)
- Access provider dashboard

### 6. Submit Test Lead
- Open incognito/private window
- Go to `http://localhost:3000`
- Auto-redirects to `/enquiry`
- Fill form and submit
- Watch real-time update on provider dashboard!

## 🐛 Troubleshooting

### Leads not distributing?
1. Check agents exist: `Supabase → leads table`
2. Verify `is_available` = true
3. Check API logs: `/api/leads/auto-distribute`
4. Review distribution rules

### Real-time not working?
1. Check Supabase realtime enabled
2. Verify subscription in console
3. Check browser dev tools (F12)

### Email verification not working?
1. Check Supabase email settings
2. Look in spam folder
3. Verify SMTP config
