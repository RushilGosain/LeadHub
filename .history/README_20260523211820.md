# Lead Distribution System

A complete Next.js application for managing and distributing leads to agents with real-time updates using Supabase.

## Features

- **Lead Management**: Create, track, and manage customer leads
- **Intelligent Lead Distribution**: Automatic assignment based on agent availability and workload
- **Agent Management**: Manage agent profiles, availability, and performance metrics
- **Agent Scheduling**: Define work schedules for each agent
- **Call Tracking**: Log calls and track agent performance
- **Real-Time Updates**: Live updates using Supabase Realtime
- **User Authentication**: Secure signup and login with Supabase Auth
- **Responsive Design**: Mobile-friendly interface with Tailwind CSS

## Database Schema

### Tables

#### `agents`
Stores agent/user information
- `id` (UUID) - Primary key, references auth.users
- `email` (TEXT) - Agent email
- `name` (TEXT) - Agent name
- `status` (TEXT) - offline, free, busy
- `phone_number` (TEXT) - Contact number
- `total_calls_received` (INT) - Incoming calls count
- `total_calls_completed` (INT) - Completed calls count
- `is_available` (BOOLEAN) - Availability status
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

#### `leads`
Stores customer lead information
- `id` (UUID) - Primary key
- `customer_name` (TEXT) - Customer name
- `customer_phone` (TEXT) - Customer phone
- `customer_email` (TEXT) - Customer email
- `source` (TEXT) - Lead source (website, phone, email, referral, other)
- `status` (TEXT) - pending, assigned, completed, cancelled
- `priority` (INT) - 0-3 (Low, Medium, High, Urgent)
- `assigned_agent_id` (UUID) - References agents table
- `assigned_at` (TIMESTAMP) - Assignment time
- `completed_at` (TIMESTAMP) - Completion time
- `notes` (TEXT) - Additional notes
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

#### `agent_schedules`
Stores agent work schedules
- `id` (UUID) - Primary key
- `agent_id` (UUID) - References agents table
- `day_of_week` (INT) - 0-6 (Sunday-Saturday)
- `start_time` (TIME) - Work start time
- `end_time` (TIME) - Work end time
- `is_working` (BOOLEAN) - Whether agent works this day
- `created_at` (TIMESTAMP)

#### `call_history`
Logs all calls made to leads
- `id` (UUID) - Primary key
- `lead_id` (UUID) - References leads table
- `agent_id` (UUID) - References agents table
- `start_time` (TIMESTAMP) - Call start time
- `end_time` (TIMESTAMP) - Call end time
- `duration_seconds` (INT) - Call duration
- `call_status` (TEXT) - in_progress, completed, missed, declined
- `notes` (TEXT) - Call notes
- `created_at` (TIMESTAMP)

## Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_DEV_SUPABASE_REDIRECT_URL=http://localhost:3000/auth/callback
```

Get these from your Supabase project dashboard:
1. Go to Settings → API
2. Copy your project URL and anon key
3. Paste them into `.env.local`

## Installation & Setup

### Prerequisites
- Node.js 18+ or higher
- npm, yarn, pnpm, or bun package manager
- Supabase account (free at https://supabase.com)

### Step 1: Clone/Create the Project

```bash
# Using v0 or downloaded
cd lead-distribution-system
```

### Step 2: Install Dependencies

```bash
# Using pnpm (recommended)
pnpm install

# Or using npm
npm install

# Or using yarn
yarn install
```

### Step 3: Set Up Supabase

1. Create a new Supabase project at https://supabase.com
2. Get your project URL and anon key from Settings → API
3. Create the `.env.local` file with your credentials
4. The database schema is already set up and ready to use

### Step 4: Run the Development Server

```bash
pnpm dev
```

The application will start on `http://localhost:3000`

### Step 5: Create Test Data

1. Go to `http://localhost:3000/auth/sign-up`
2. Create a new account (check your email to verify)
3. Sign in to the dashboard
4. Start adding leads and agents

## API Endpoints

### Lead Distribution
**POST** `/api/leads/distribute`

Request:
```json
{
  "leadId": "uuid",
  "useAutoAssignment": true
}
```

Response:
```json
{
  "success": true,
  "leadId": "uuid",
  "assignedAgentId": "uuid"
}
```

### Log Call
**POST** `/api/calls/log`

Request:
```json
{
  "leadId": "uuid",
  "agentId": "uuid",
  "callStatus": "completed",
  "duration": 300,
  "notes": "Call notes"
}
```

Response:
```json
{
  "success": true,
  "leadId": "uuid",
  "callLogged": true
}
```

### Agent Schedule
**GET/POST** `/api/agents/schedule`

GET Request (fetch):
```
?agentId=uuid
```

POST Request (save):
```json
{
  "agentId": "uuid",
  "dayOfWeek": 1,
  "startTime": "09:00",
  "endTime": "17:00",
  "isWorking": true
}
```

## Features Explained

### Lead Distribution Algorithm

The system automatically assigns leads based on:

1. **Agent Availability**: Prioritizes agents marked as available
2. **Workload**: Assigns to agents with fewer calls
3. **Schedule**: Checks if agent is working at current time
4. **Status**: Prefers agents with "free" status over "busy"

### Real-Time Updates

The agent list updates in real-time using Supabase Realtime subscriptions. Changes to agent status, availability, and call counts are reflected immediately across all connected clients.

### Lead Status Flow

```
pending → assigned → completed
   ↓
cancelled
```

### Agent Status Options

- **offline**: Not available
- **free**: Available and ready to take calls
- **busy**: Currently on a call

## Usage Examples

### Adding a Lead

1. Go to Dashboard
2. Click "Manage Leads" tab
3. Fill in the form:
   - Customer Name
   - Phone Number
   - Email (optional)
   - Source (Website, Phone, Email, Referral, Other)
   - Priority (Low, Medium, High, Urgent)
4. Click "Add Lead"

### Assigning a Lead

1. Go to "All Leads" section
2. Find a pending lead
3. Click the "Assign to..." dropdown
4. Select an agent
5. The lead is automatically assigned

### Managing Agents

1. Go to "Agents" tab
2. View all registered agents
3. Click "Available" or "Not Available" to toggle availability
4. Monitor their call metrics

### Setting Agent Schedule

Agent schedules are managed through the API:

```bash
curl -X POST http://localhost:3000/api/agents/schedule \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent-uuid",
    "dayOfWeek": 1,
    "startTime": "09:00",
    "endTime": "17:00",
    "isWorking": true
  }'
```

## Troubleshooting

### Email Verification Issues
- Check spam folder for verification email
- Supabase requires email confirmation before full access
- You can disable this in Supabase Auth settings if needed

### Authentication Errors
- Ensure `.env.local` has correct Supabase credentials
- Verify your Supabase project is active
- Check browser console for detailed error messages

### Real-Time Updates Not Working
- Ensure Supabase Realtime is enabled in your project
- Check browser console for WebSocket errors
- Verify Row Level Security policies allow access

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| "Supabase URL not found" | Add NEXT_PUBLIC_SUPABASE_URL to .env.local |
| "Email verification loop" | Verify email address or disable in Supabase settings |
| "Real-time updates not working" | Check WebSocket in browser DevTools, enable Realtime in Supabase |
| "RLS policy error" | Ensure user is authenticated and RLS policies allow access |
